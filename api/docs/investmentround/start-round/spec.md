## 목적

시드머니와 투자 원칙을 설정하여 새 투자 라운드를 시작한다.

- 모의투자 환경 초기화: 거래소별 시드머니, 긴급 자금 상한, 투자 원칙 설정
- 거래소별 지갑과 초기 잔고 자동 생성
- 투자 복기를 위한 원칙 설정 기반 마련

## 라운드 시작 조건

- 사용자당 진행 중인 라운드는 1개만 허용한다
- 이미 진행 중인 라운드가 있으면 새 라운드를 시작할 수 없다

## 시드머니 설정

- 시드머니는 거래소별로 입력하며, 각 거래소의 기축통화 단위로 해석한다
- 시드머니를 넣지 않을 거래소는 0으로 둘 수 있다. 단, 최소 한 개 거래소에는 시드머니를 넣어야 한다
- 같은 거래소에 시드머니를 중복으로 입력할 수 없다
- 거래소별 한도는 다음과 같으며, 시드머니를 넣는 경우에만 적용한다

| 거래소 | 기축통화 | 최소 | 최대 |
|--------|---------|------|------|
| 업비트 | KRW | 100만 | 5,000만 |
| 빗썸 | KRW | 100만 | 5,000만 |
| 바이낸스 | USDT | 1,000 | 30,000 |

## 시드 총액 집계

- 시드 총액은 원화 단일 통화로 집계하며, 수익률과 투자 복기의 투입 자금 기준값이 된다
- USDT 시드머니는 라운드 시작 시점 시세로 원화 환산하여 합산한다
- 환산액은 라운드 시작 시점에 확정되며, 이후 환율이 변해도 시드 총액은 변하지 않는다

## 긴급 자금 투입 상한

- 라운드 시작 시 1회 투입 상한을 설정한다
- 상한은 원화 기준이며 최대 100만원 (0원 = 긴급 자금 미사용)
- 긴급 충전 가능 횟수: 최대 3회
- 라운드 중 긴급 충전은 거래소를 선택해 해당 기축통화로 투입한다. 세부 규칙은 긴급 충전 명세를 따른다

## 투자 원칙 설정

- 각 원칙은 선택적으로 활성화/비활성화 가능하다
- 서버 검증: 비율은 0 초과, 횟수는 1 이상 정수만 확인한다

| 원칙 | 원칙 유형 | 설정값 의미 | 단위 |
|------|----------|------------|------|
| 손절 | LOSS_CUT | 보유 코인 손실률이 설정값에 도달하면 매도해야 함 | % |
| 익절 | PROFIT_TAKE | 보유 코인 수익률이 설정값에 도달하면 매도해야 함 | % |
| 추격 매수 금지 | CHASE_BUY_BAN | 일일 상승률이 설정값 이상인 코인 매수 금지 | % |
| 물타기 제한 | AVERAGING_DOWN_LIMIT | 코인별 물타기 최대 횟수 | 회 |
| 과매매 제한 | OVERTRADING_LIMIT | 일일 주문 최대 횟수 | 회 |

## 라운드 시작 시 초기화

- 진행 중 상태의 새 라운드를 생성한다 (회차: 이전 라운드 수 + 1)
- 활성화된 투자 원칙을 생성한다
- 거래소별 지갑을 모두 자동 생성한다
  - 시드머니를 넣은 거래소 지갑: 입력한 시드머니를 기축통화 가용 잔고로 설정한다
  - 시드머니가 0인 거래소 지갑: 잔고 없이 생성한다 (송금을 받을 수 있도록 지갑 자체는 존재해야 한다)
