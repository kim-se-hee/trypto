## 목적

거래소의 실제 상장 목록과 플랫폼의 마켓 목록을 지속적으로 일치시킨다.

현재 마켓 목록은 시스템 시작 시점에 한 번만 확정되어, 이후 거래소에서 신규 상장이나 거래지원 종료가 발생해도 반영되지 않는다. 
이로 인해 거래지원이 종료된 코인이 마지막 시세로 굳은 채 노출되어 되고, 신규 상장 코인은 재기동 전까지 존재하지 않는 것으로 취급된다. 
이 기능은 상장 목록을 주기적으로 동기화하고, 거래지원이 종료된 마켓을 사용자로부터 숨긴다.

## 상태의 출처

- 상태 감지·판정·전이·동기화는 시세 수집기가 한다. 코인은 `거래중`과 `거래지원 종료` 두 상태를 갖는다.
- 이 문서는 api가 전파받은 상태를 어떻게 반영하는지를 다룬다. collector가 상태 변화를 발행하면 api가 받아 자신의 저장소와 화면에 반영한다.

## 신규 상장 반영

- 거래소에 새로 상장된 코인이 전파되면 해당 코인을 DB에 등록하여 목록과 주문 대상에 포함한다. 거래지원 종료가 이미 있는 코인의 상태를 바꾸는 것과 달리, 신규 상장은 저장소에 없던 코인을 새로 추가하는 것이다.
- 거래지원 종료됐던 코인이 다시 상장되는 경우는 새로 추가하지 않고, 기존 코인의 상태만 `거래중`으로 되돌린다.

## 데이터 보존

- 거래지원 종료 시 어떤 데이터도 삭제하지 않는다. 마켓 정보, 마지막 시세, 과거 캔들, 사용자 보유 잔고를 모두 보존한다.
- 중단하는 것은 시세 수집뿐이다. 마지막 시세는 종료 시점 값으로 유지된다.

## 노출

- 거래지원 종료 코인은 마켓 탭, 입출금 탭, 보유 자산 목록 화면 등 코인이 보이는 모든 화면에서 숨긴다.  
- 화면에서 숨긴 코인은 총자산·수익률·랭킹 계산에서도 뺀다. 목록에는 없는 코인이 총자산에는 포함되어 있으면 코인별 금액을 합쳐도 총자산과 맞지 않게 되기 때문이다.

## 검증

- 거래지원 종료 마켓에 대한 신규 주문 요청은 거절한다. 화면에서 숨기는 것과 별개로 서버가 직접 검증한다.
- 거래지원 종료 시점에 남아 있는 미체결 주문은 시스템이 자동으로 취소하여 잠긴 금액을 사용자 잔고로 돌려준다. 
- 마켓이 모든 화면에서 숨겨져 사용자가 직접 취소할 경로가 사라지므로, 자동 취소로 회수를 보장한다. 이 취소는 잠긴 금액을 잔고로 되돌릴 뿐, 보유 중인 코인을 매도하지 않는다.
- 거래지원 종료 코인에 대한 송금 요청은 거절한다.

## 하지 않는 것

- 엔진이 오더북을 임의로 삭제하지 않는다. 미체결 주문 제거는 api가 발행한 취소 이벤트로만 이루어진다(위 자동 취소 포함).
- 거래지원 종료 코인 보유분의 강제 매도나 보상은 하지 않는다.
