# 비ASCII 심볼 캔들 조회 허용

- `CandleFilter`의 심볼 검증 정규식이 `[A-Za-z0-9_-]+`라 한자 심볼(예: `币安人生`)을 거절하여, 데이터가 있어도 캔들 API가 400을 반환한다. 검증을 완화해 비ASCII 심볼을 허용한다.

# 상태 컬럼 추가

- `exchange_coin`(또는 `exchange_market`)에 상태 컬럼을 추가한다(거래중 / 거래지원 종료).

# 사용자 화면 즉시 반영 (STOMP)

- 상태 변화 수신 시 STOMP로 "마켓 제거/추가" 메시지를 보내, 새로고침 없이 목록에서 사라지거나 나타나게 한다.

# 미체결 주문 자동 취소

거래지원 종료 마켓에 남은 미체결 주문을 시스템이 자동 취소해 잠긴 금액을 원복 시킨다.
이때 자동 취소는 별도 use case·애플리케이션 서비스로 둔다.** 유저 취소(`CancelOrderUseCase`)와 로직이 겹치더라도 공유 협력자를 만들지 않는다.
