RegretReport : 투자 원칙 위반이 자산에 끼친 영향을 되짚는 복기 리포트. 배치가 거래소별로 하나씩 만든다.
RegretReports : 한 라운드에 속한 거래소별 리포트의 묶음. 조회 시점에 원화로 환산해 합친다.
RoundRegretReport : 거래소별 리포트를 라운드 하나로 합친 조회 결과.
RuleImpact : 개별 투자 원칙 위반이 자산에서 깎아낸 금액.
ViolationDetail : 원칙 위반 한 건의 상세 내역. 위반 손익 총액을 들고, 그중 매도로 확정된 몫을 RealizedLoss 로 소유한다.
RealizedLoss : 실현일에 금액이 확정된 위반 손익 한 조각. 부분 실현이 여러 날에 걸치면 여러 개다.
AssetSnapshot : 거래소별 시점 자산 스냅샷.
ViolatedOrder : 원칙을 위반한 주문.
